# 公开链接

需要 `shares:manage`。创建前从用户指令中确定类型、对象、日期范围与开放模块；缺少范围时提出具体问题，已有明确范围时直接执行。

`create_share` 的类型为 `diary`、`project` 或 `task`。项目和任务分享需要 `targetId`；日期用 `from` / `to`，开放模块从 `overview`、`tasks`、`progress` 中明确选择。

`from` / `to` 是展示日报的日期范围，不是链接自动到期时间。链接不会在 `to` 之后自动失效；需要停止公开时关闭链接。

日报公开链接会展示范围内全团队完整已提交日报，不能按单个成员限制。用户要求“只分享我的日报”时，解释现有能力并等待用户选择适当范围，不能悄悄扩大为全团队。项目和任务分享仅展示相应目标与授权模块；草稿及未重提修改不会进入公开结果。

用 `list_my_shares` 分页定位本人链接及其当前状态，`close_share` 只关闭本人创建的链接。创建的链接 URL 按成功回执原样返回，不自行拼接令牌或地址。重放的创建回执是历史记录，不证明链接现在仍开放；需要确认时重新读取链接列表。
