# 在单台 ECS 上采用双版本槽位、单活发布

Status: superseded by [ADR 0005](0005-local-manual-single-instance-release.md)（2026-09-21 撤回双槽与自动发布；本文件第二段的流量开放边界仍被继承）

2026-09-20 CI/CD 设计讨论确认：日序沿用现有单台 ECS、SQLite 与本地附件，保留两个应用版本槽位，由 Nginx 切换服务入口；生产数据库始终只由一个应用进程使用，发布接受短暂维护并优先保证数据完整性。这一选择允许分别准备新旧代码，符合现有资源与单应用资源所有者约束；不引入双应用同时服务或双机容灾，也不承诺切换 Nginx 即可回退数据库。

同日补充确认：只有在尚未重新开放流量时，才允许自动恢复配套旧代码与数据库/附件备份；一旦可能开放流量，就保留新增数据、冻结后续发布并由人工处理异常。选择这个边界是为了避免用发布前快照覆盖新版本已接受的工作记录，代价是开放后的故障不保证一键切回旧版本。

逐项决策及完整设计见工作区 `.scratch/daily-flow-cicd/design.md`。用户于 2026-09-20 确认完整方案收口，本决策已接受；自动化部署实现另行推进。
