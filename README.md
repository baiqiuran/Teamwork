# 日序 · 成员入口

任务 01 的可运行实现：建立单团队、邮箱密码登录、邀请注册、查看账号、生成和撤销自己的邀请。日报、项目、任务和公开分享属于后续任务，本次尚未实现。

## 本机运行

需要 Node.js 24.15 或更高的 24.x 版本及 npm。

```powershell
npm ci
npm run build
npm start
```

在本目录运行。应用默认打开在 `http://127.0.0.1:4310`。首次启动会在终端打印带引导密钥的创建团队链接；打开该链接，填写团队名称、姓名、邮箱及至少 12 个字符的密码。团队建立后，该入口自动关闭。没有预置账号或密码。

已建立团队后可直接打开首页登录。任何成员都能生成邀请链接，在另一浏览器或隐私窗口中接受邀请，即可验证第二位成员加入。邀请有效期为生成后的 7 × 24 小时，单次使用；仅生成者可以撤销，撤销不移除已加入的成员。

本阶段按确认方案只监听本机地址。邀请链接只用于本机验证，尚不能发送给其他电脑使用。后续联网部署需要明确主机、HTTPS 和可信来源配置。

## 数据与账号

- 数据保存在 `data/daily-flow.sqlite` 及其 WAL 文件；重启服务保留成员、会话与邀请。
- 首次启动时生成引导密钥；团队未建立前重启会生成新的链接。`DAILY_SETUP_KEY` 可由本机操作者显式指定，主要用于自动化测试。
- `PORT` 可修改端口；`DAILY_DATABASE_PATH` 可指定独立数据库文件。测试不使用正常运行的数据库。
- 密码使用带随机盐的 scrypt；会话和邀请只保存令牌摘要。会话有效期 7 天，退出时立即作废。
- 所有写接口校验来源，成员身份来自 HttpOnly 会话 Cookie；初始创建还要求本机请求和引导密钥。
- 邀请链接仅生成时展示一次；离开后如需再次分享，可生成新链接并撤销不再使用的邀请。
- 邮箱作为账号标识，本阶段没有邮件验证、发送邮件或密码找回服务。

## 验证

```powershell
npm run typecheck
npm run test:api
npm run build
npm run test:ui
```

`npm test` 执行类型检查与构建、业务接口测试及浏览器测试。浏览器测试使用本机 Microsoft Edge，无需下载浏览器；服务在 4311 端口启动，每次使用独立的 `data/e2e-*.sqlite` 测试数据库，测试后服务退出。

业务测试通过真实 HTTP 接口操作独立 SQLite 数据库，不通过数据库查询验证结果。覆盖身份边界、重启后登录、邀请加入、权限、到期、撤销、并发接受、来源检查和频率限制；时钟只在应用边界注入。

页面流程覆盖创建团队、两位成员加入、刷新会话、邀请管理、退出和登录，并检查 390px 窄屏无横向溢出。截图在 `test-results/`。

修改前端后运行 `npm run build` 再刷新页面；`npm run dev` 监听服务端改动并重启。
